📘 app.py 用法说明（中文版）

将电子书转换为有声书，支持使用多种语音合成（TTS）模型。你可以启动 Gradio 图形界面，或通过无界面模式（headless）直接转换。

🧾 基本用法（usage）：

python app.py [参数]

🆘 常规参数：

参数说明
-h / --help显示帮助信息并退出。
--session SESSION会话名称：当中断、崩溃或使用自定义模型/音色时可用于恢复。

💡 Gradio / 图形界面专属参数：

参数说明
--share启用 Gradio 的公开共享链接（便于远程访问）。

🖥️ 无界面模式（--headless）专属参数：

参数说明
--headless启动脚本的无界面模式（直接转换，无需 GUI）。
--ebook EBOOK指定单个电子书文件路径进行转换（不能和 --ebooks_dir 同时使用）。
--ebooks_dir EBOOKS_DIR指定电子书所在目录（支持批量转换，不能和 --ebook 同时使用）。
--language LANGUAGE指定电子书语言代码（详见 ./lib/lang.py 文件中的支持语言列表）。

🎙️ 语音合成参数（适用于所有模式）：

参数说明
--voice VOICE（可选）指定用于声音克隆的音频文件路径。如未提供则使用默认音色。
--device {cpu,gpu,mps}指定使用的计算设备：CPU / GPU / Apple MPS，默认为 ./lib/conf.py 中设定值。如 GPU 不可用会自动回退到 CPU。
--tts_engine {...}指定 TTS 引擎，支持：XTTSv2, BARK, VITS, FAIRSEQ, TACOTRON2, YOURTTS（区分大小写与小写形式都可）。需与所选语言兼容。
--custom_model CUSTOM_MODEL（可选）自定义模型 .zip 路径，需包含模型必须文件，详见 ./lib/models.py。
--fine_tuned FINE_TUNED（可选）微调模型路径，默认为内置模型。
--output_format OUTPUT_FORMAT（可选）输出音频格式，如 mp3、wav 等。默认值见 ./lib/conf.py。
--output_dir OUTPUT_DIR（可选）输出文件夹路径，默认值见 ./lib/conf.py。

🔧 XTTS 专属参数：

参数说明
--temperature TEMPERATURE模型温度（越高越有创造性），默认来自 config.json。
--length_penalty LENGTH_PENALTY自动回归解码器的长度惩罚，控制生成长度。
--num_beams NUM_BEAMS控制生成候选序列数量，建议 ≥ length_penalty，默认来自配置。
--repetition_penalty REPETITION_PENALTY惩罚重复内容，防止生成重复语句。
--top_k TOP_KTop-K 采样（值越小生成越稳定、速度越快）。
--top_p TOP_PTop-P 采样（值越小生成越稳定、速度越快）。
--speed SPEED控制语速（发音快慢）。
--enable_text_splitting启用文本自动分段朗读，通常效率不高。

🧠 BARK 专属参数：

参数说明
--text_temp TEXT_TEMP文本温度，默认 0.2，越高越有创造性。
--waveform_temp WAVEFORM_TEMP音频波形温度，默认 0.2，越高越有创造性。

📦 版本信息：

参数说明
--version显示当前脚本版本并退出。

基本用法

  • • Linux/MacOS：
    ./ebook2audiobook.sh --headless --ebook <path_to_ebook_file> \
        --voice [path_to_voice_file] --language [language_code]
  • • 视窗
    ebook2audiobook.cmd --headless --ebook <path_to_ebook_file>
        --voice [path_to_voice_file] --language [language_code]
  • • [--ebook]：电子书文件的路径
  • • [--voice]：语音克隆文件路径（可选）
  • • [--language]：ISO-639-3 语言代码（例如：ita 代表意大利语，eng 代表英语，deu 代表德语……）。
    默认语言为 eng，--language 为可选参数，用于在 ./lib/lang.py 中设置默认语言。ISO
    -639-1 双字母代码也受支持。

自定义模型 Zip 上传示例

（必须是包含必需模型文件的 .zip 文件。XTTSv2 示例：config.json、model.pth、vocab.json 和 ref.wav）

  • • Linux/MacOS
    ./ebook2audiobook.sh --headless --ebook <ebook_file_path> \
        --voice <target_voice_file_path> --language <language> --custom_model <custom_model_path>
  • • 视窗
    ebook2audiobook.cmd --headless --ebook <ebook_file_path> \
        --voice <target_voice_file_path> --language <language> --custom_model <custom_model_path>
  • • <custom_model_path>：文件路径model_name.zip，必须包含（根据 tts 引擎）所有必需文件
    （参见 ./lib/models.py）。

IndexTTS是一个基于 GPT 风格的文本转语音 (TTS) 模型，主要基于 XTTS 和 Tortoise 算法。它能够通过拼音纠正汉字发音，并通过标点符号控制任意位置的停顿。我们增强了系统的多个模块，包括改进说话人条件特征表示，并集成 BigVGAN2 以优化音频质量。我们的系统基于数万小时的数据进行训练，达到了最佳性能，超越了目前流行的 TTS 系统，例如 XTTS、CosyVoice2、Fish-Speech 和 F5-TTS。

使用说明

环境设置

  1. 1. 下载此存储库：
git clone https://github.com/index-tts/index-tts.git
  1. 2. 安装依赖项：

创建新的 conda 环境并安装依赖项：

conda create -n index-tts python=3.10
conda activate index-tts
apt-get install ffmpeg
# or use conda to install ffmpeg
conda install -c conda-forge ffmpeg

安装PyTorch，例如：

pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118

笔记

如果您使用的是 Windows，则安装时可能会遇到错误pynini： ERROR: Failed building wheel for pynini 在这种情况下，请pynini通过以下方式安装conda：

# after conda activate index-tts
conda install -c conda-forge pynini==2.1.6
pip install WeTextProcessing --no-deps

IndexTTS作为包安装：

cd index-tts
pip install -e .
  1. 3. 下载模型：

下载方式huggingface-cli：

huggingface-cli download IndexTeam/IndexTTS-1.5 \
  config.yaml bigvgan_discriminator.pth bigvgan_generator.pth bpe.model dvae.pth gpt.pth unigram_12000.vocab \
  --local-dir checkpoints

推荐给中国用户。 如果下载速度慢，可以使用镜像：

export HF_ENDPOINT="https://hf-mirror.com"

或者通过wget：

wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/bigvgan_discriminator.pth -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/bigvgan_generator.pth -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/bpe.model -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/dvae.pth -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/gpt.pth -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/unigram_12000.vocab -P checkpoints
wget https://huggingface.co/IndexTeam/IndexTTS-1.5/resolve/main/config.yaml -P checkpoints

笔记

如果您更喜欢使用IndexTTS-1.0模型，请在上面的命令中替换IndexTeam/IndexTTS-1.5为。IndexTeam/IndexTTS

  1. 4. 运行测试脚本：
# Please put your prompt audio in 'test_data' and rename it to 'input.wav'
python indextts/infer.py
  1. 5. 用作命令行工具：
# Make sure pytorch has been installed before running this command
indextts "大家好，我现在正在bilibili 体验 ai 科技，说实话，来之前我绝对想不到！AI技术已经发展到这样匪夷所思的地步了！" \
  --voice reference_voice.wav \
  --model_dir checkpoints \

使用--help来查看更多选项。

indextts --help
